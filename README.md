## Project

Interactive terminal-style resume/curriculum.

## Commands

| Command      | Description                          |
| ------------ | ------------------------------------ |
| `help`       | List all commands                    |
| `whoami`     | Professional summary                 |
| `experience` | Work history                         |
| `education`  | Academic background & certifications |
| `skills`     | Tech stack by category               |
| `projects`   | Projects grouped by category         |
| `contact`    | Links and email                      |
| `clear`      | Clear terminal                       |
